# PrintableCheckList 首个自助式 Beta 规格

状态：待实现；基线：`ad81d6933cd8b31bba93dbfe9abc75e45ab47c1a`；日期：2026-07-24。

本规格只定义首个 Beta 的交付与发布条件。它不授权开发、部署、App Store Connect 操作或扩展产品范围。所有“现状”均以该基线提交为准，未采用工作树中 `PrintableCheckList/Views/PreviewView.swift`、`.agents/`、`.claude/`、`skills-lock.json` 的未提交改动。

## 1. 范围、主流程与非目标

### 精确范围

目标用户是为尚不能独立收拾行李的孩子负责的家庭准备负责人；唯一主场景是三晚以上跨城市或跨境亲子旅行，在出发前 48 小时完成最终打包。

唯一主流程如下：

1. 用户离线创建或打开清单，或输入旅行情境。
2. 用户主动发起 AI；未拥有 Pro 时显示一次性 Pro 付费墙，购买/恢复成功后返回原输入。
3. 用户选择托管 AI 或 BYOK。托管 AI 生成可编辑草稿；BYOK 直接调用用户选择的服务商。
4. 用户逐项编辑、删除、排序，选择保存后才成为本地最终清单；取消、失败或未确认不得改写原清单。
5. 用户可对已保存清单发起 AI 补充；补充结果仍须人工确认后合并。
6. 用户在同一确定性版式的预览中选择 A4 或 Letter，导出打印就绪 PDF，或调用系统打印；本地编辑和已有清单预览在无网络时可用。
7. 用户可自愿确认“已生成纸张且用于最终打包”；这才是打印成功，系统回调不是打印成功证明。

免费能力：手工创建、批量粘贴、重命名、编辑、删除、排序、本地存储、旧数据迁移、已存在 iCloud 行为、预览、PDF 导出与系统打印。免费用户不能发起真实 AI 操作。

Pro：可恢复、非消耗型一次购买；永久解锁 AI 入口，且每自然月至多 20 次托管 AI 操作。美国 Beta 基准价为 $2.99；不承诺 Beta 后价格不变，但已购买用户永久保有 Pro 与披露的月度规则。

BYOK：仍需 Pro；密钥只在设备 Keychain；请求从设备直接到用户所选服务商；不占用 20 次托管额度。它不是托管 AI 的免费替代，也不得将用户密钥、内容或搜索结果发送到产品方服务。

### 明确不做

不做 App 内完成状态、提醒、截止日期、通知、Todo/项目/习惯管理、订阅、点数包、旅行次数、模板市场、Android、Web、团队协作、指派、评论、分享链接、账号系统、Supabase 清单云同步或自动保存 AI 草稿。不得将系统打印说成 PDF 导出，或将 iCloud/原型/Sandbox 说成 Production 可用证据。

“云同步”仍不是本 Beta 能力：没有真实 Supabase Auth、RLS 和端到端同步证据前，Supabase 只可用于托管 AI、额度和经同意的统计，绝不可作为清单备份或跨设备恢复承诺。

## 2. 功能与商业规则

### AI 操作计量与额度

一次托管 AI 操作是用户主动获得一次可呈现结果的请求，计量由服务端以操作 ID 执行：

| 用户行为 | 是否计入 | 规则 |
| --- | --- | --- |
| 初次生成草稿 | 是，1 次 | 仅在服务端完成并返回草稿时永久计入。 |
| 重新生成 | 是，1 次 | 每次新的用户确认请求使用新的操作 ID。 |
| AI 补充 | 是，1 次 | 结果在用户确认前不得改写既有清单。 |
| 联网事实核查 | 是，1 次 | 仅当用户明确要求或系统识别为时效性事实且实际执行联网核查。 |
| 内部模型重试、JSON 修复、工具调用 | 否 | 归入同一操作成本；不得额外扣额。 |
| 用户取消、网络失败、交易校验失败、模型失败 | 否 | 必须释放预留；不能把失败变成额度消耗。 |

额度规则：

- 每个由 Apple 原始交易标识代表的 Pro 身份，每月最多 20 个 `reserved` 或 `completed` 操作；`released` 不计入。
- 首次成功预留时，服务端校验客户端提交的 IANA 时区并永久固定为该身份的有效时区；之后改设备时区不改变月界线。自然月按该时区当地每月 1 日 00:00 到下月 1 日 00:00；未用额度不结转。
- 同一操作 ID 必须同时作为 HTTP `Idempotency-Key`。已完成操作只重放已存响应，不重复调用模型或扣额；有效预留中的相同 ID 返回“处理中”，不得另扣额；其他身份复用该 ID 必须失败。
- 预留时长最多 10 分钟。请求异常时立即释放；崩溃残留由下一次预留清理过期记录。完成写入与已存响应必须原子化；无法写入时返回失败且释放。
- 额度上限、身份校验或账本不可用时 fail closed：不调用模型、不消耗额度，并显示可重试的明确错误。离线时托管 AI 不可用；本地清单仍可编辑、预览、导出和打印。

### 购买与恢复状态

| 状态/失败 | 必须行为 |
| --- | --- |
| 未购买且发起真实 AI | 显示 Pro 付费墙；保留旅行输入，不执行 AI 网络请求。 |
| 购买成功且本机验证 | 完成交易、刷新权益、回到原 AI 请求；服务端仍须逐次校验交易 JWS。 |
| 用户取消或待审批 | 不改变权益；显示可继续使用免费手工能力。 |
| 恢复购买 | 调用 Apple 同步后刷新；无购买时明确说明；成功时恢复永久 Pro，不恢复“点数”。 |
| 退款/撤销 | 本机或服务端发现撤销后立即禁止托管/BYOK 新 AI 操作；已保存本地清单、PDF 和打印不删除。 |
| Apple 服务/产品信息不可用 | 不猜测权益。已确认的本机权益可继续显示 Pro，但无法开始需重新核验的托管操作；未确认权益只能手工使用，并提供重试/恢复。 |
| 无网络 | 不能购买、恢复、托管 AI 或联网核查；不能降级为免费托管 AI；允许离线本地功能与已保存 PDF。 |

## 3. AI、草稿、来源和错误生命周期

AI 草稿仅存在于生成界面内：`请求中 → 成功草稿（可编辑） → 用户保存为最终清单`，或 `取消/失败/放弃 → 不保存`。补充草稿与原清单分离，确认前绝不覆盖。最终清单只含标题和顺序清单项；来源不写入清单项、iCloud 清单或 PDF，除非未来另行定义可引用附录。

普通亲子旅行打包清单默认不联网。联网仅用于票务规则、签证/入境要求、天气、汇率、价格、新闻、排行、营业时间等会随时间变化且会影响清单内容的事实请求；静态物品建议不得为“看起来更智能”而联网。自动模式必须对静态打包请求返回未搜索；关闭模式绝不搜索；始终搜索仅在 BYOK 支持的服务商中可用。

若实际联网，草稿页面必须显示每个来源的标题、主机、可打开 HTTPS URL，及可用时发布日期/摘要，并标示“仅供核查，非正确性保证”。搜索失败时可在不搜索的前提下重新生成，且必须标明该结果未进行核查。普通未联网结果不显示空的来源区。

托管 AI Beta 必须二选一后才可发布：实现上述按需联网核查并返回来源，或在产品/UI/商店文案中明确“托管 AI 不提供联网事实核查”，且只允许 BYOK 的受支持服务商提供该功能。当前基础代码采取后者；不得把返回的空 `sources` 视为来源能力。

错误状态必须可观察：保留输入和未保存草稿；将购买/权益无效、月额度已满、网络超时、服务不可用、联网不可用、无效响应分别显示为可本地化的用户可行动错误；不得显示 JWS、密钥、请求正文、供应商原始错误或内部异常。重试同一次已发送请求必须复用原操作 ID；用户明确“重新生成”才产生新操作 ID。

## 4. 打印就绪 PDF 与打印

本 Beta 的标准成品是打印就绪 PDF：固定页面尺寸、设备无关、可保存/分享/打印的 PDF，而不是屏幕 ScrollView 或 `UIPrintInteractionController` formatter。最低质量标准：

- A4 和 US Letter 均可选；默认适合用户当前地区，且选择在本次导出/打印中明确可见。
- 4–7 个分组、每项独立可核对、不截断文字、无重叠、无孤立标题或空白页；默认一页，必要时最多两页。超出两页时必须在导出前显示可执行的缩减/拆分提示，不能静默截断。
- 同一份已保存清单、纸张尺寸、字体缩放策略和生成时间，预览、导出 PDF 和系统打印必须复用同一渲染器/布局输入。自动化像素/文本断言须证明三个输出的标题、项目顺序、项目数、页数和页边距一致。
- “打印”只打开系统打印面板并可打印同一 PDF；系统完成回调只记录 `system_print_completed`，不等于 `print_success`。`print_success` 仅由用户明确确认“已生成纸张并用于最终打包”产生。

## 5. 数据、隐私和安全边界

本地清单标题、项目、排序和旧版迁移数据是离线可用的本地数据；iCloud 开启时由用户 Apple ID 的 `NSUbiquitousKeyValueStore` 处理。保留生产 bundle identifier `com.wehack.PrintableCheckList` 与 `keyProjects` 迁移。不得因 AI、退款或统计选择删除用户本地清单。

托管 AI 最小传输字段：主题/要求、现有清单标题、最多 200 项、界面语言、IANA 时区、操作 ID 和 StoreKit JWS。JWS 不得持久化或写日志；请求正文不得写额度表或错误日志。账本可保存原始交易标识、环境、固定时区、月份、操作状态、失败类别和为幂等重放所必需的已完成响应。BYOK 密钥只在 Keychain，且不得进入 UserDefaults、iCloud、Supabase、清单、日志或分析。

所有服务端密钥（Supabase secret/service role、模型密钥、Apple Server API 私钥、共享 HMAC secret）只能在对应部署平台的 secrets。App、仓库、日志、错误响应、Analytics 和崩溃报告中一律禁止。Edge Function 只能以服务端身份执行额度 RPC；额度表启用 RLS，`anon` 和 `authenticated` 无表/函数权限。

Sandbox 与 Production 必须物理隔离：不同 Supabase 项目、数据库/账本、Edge Function 部署、Vercel 项目/环境变量、Apple 环境、模型凭据和监控/告警；两侧不得共享交易 ID 账本或密钥。Debug 仅使用 Sandbox HTTPS 端点；Release 没有默认端点，只有通过忽略的本地配置或 Xcode Cloud 注入的 Production URL 才可启用；任何环境、JWS 或 verifier 回传环境不匹配都拒绝请求。

隐私披露必须在仓库中英版本、公开隐私页和 App Store Connect 三处逐项一致，至少覆盖：本地/iCloud、托管 AI 的传输与下游处理方、StoreKit JWS 验证、账本字段、BYOK Keychain、可选统计、未保存请求正文/JWS、删除入口、联系邮箱和生效日期。

**已确认的数据保留与删除要求（发布门槛）**：托管 AI 的操作明细与可重放生成响应在操作完成或释放后保留 31 天，随后自动删除；安全/计费所需的去标识成本聚合数据最多保留 13 个月。Beta 必须提供应用内“请求删除托管 AI 数据”入口，返回服务端工单 ID 和完成状态，并在公开隐私页、App Store Connect 披露和中英仓库隐私文档中写明这些时限。当前账本会持久化已完成响应且仅提供邮件删除请求，因此上述自动删除、入口和可验证 SLA 都是发布前必须实现和演练的能力。

可选清单快照统计继续坚持单独、明确同意；关闭后删除当前安装上传的快照，失败显示可重试错误。它不得承载 Beta 漏斗，除非漏斗事件本身做到不上传清单文本且获得独立、明确同意或满足适用的匿名化标准。

## 6. 最小隐私友好漏斗

Beta 必须新增独立于清单快照的事件管道；默认只记录最小化的匿名安装/会话标识、事件名、时间、App 版本、Storefront/地区粗粒度、实验批次和错误类别，不记录主题、清单标题/项目、JWS、API Key、来源 URL 或模型响应。事件发送失败不得重试阻塞主流程。

| 事件 | 触发定义 | 指标 |
| --- | --- | --- |
| `ai_paywall_entered` | 已输入亲子旅行情境并主动尝试真实 AI，因未有 Pro 看到付费墙 | 独立付费墙触发用户（分母）。 |
| `pro_purchase_completed` | StoreKit 已验证权益刷新为 Pro | 购买人数；购买转化率 = 购买人数 / 付费墙触发用户。 |
| `paid_ai_output_completed` | 购买后 7 天内，托管或 BYOK AI 结果被用户确认保存，且已导出 PDF 或发起系统打印 | 7 日付费输出完成数（每人最多计一次）。 |
| `pdf_export_completed` | PDF 文件成功生成并交给系统保存/分享 | PDF 成品率；不等于打印成功。 |
| `system_print_completed` | 系统打印控制器成功回调 | 只用于诊断；不等于纸张使用。 |
| `print_success_confirmed` | 用户主动确认纸张已产生且用于最终打包 | 纸张成功人数；未答复为 unknown。 |
| `managed_ai_operation_completed` | 账本完成一项操作 | 每购买 cohort 30 天变动成本率分母关联与异常率。 |

两批各 100 名独立 `ai_paywall_entered` 用户：每批至少 8 人购买且至少 5 人在 7 天内完成付费 AI 输出。第一批失败仅允许按观察到的单一断点调整一次；第二批仍失败，停止投资该 AI 亲子旅行定位但保留旧版能力。首 20 名完成者中，纸张成功 >=8 保留纸张优先；4–7 改 PDF 优先；0–3 否决纸张核心差异。每 cohort 购买后 30 天的全部模型、搜索、工具和内部重试成本 / 实际净收入：<=5% 继续，>5% 且 <=15% 调整，>15% 不得将 $2.99 + 20 次作为正式模式。

### 人工和真实环境 E2E（逐项记录日期、环境、操作者、匿名交易/操作 ID、结果）

1. 两台真机：Sandbox 购买、取消、待审批、恢复、退款/撤销后的客户端与服务端拒绝；验证服务只接受相同 Sandbox 环境。
2. 独立 Production App Store 交易与 Production verifier/Edge/账本/模型的端到端购买、恢复、一次生成、补充、额度计数、失败释放和跨月；确认没有读取 Sandbox URL、数据或密钥。
3. 真实 Production secrets 清单双人核验：每项存在于正确平台、非空、环境正确、最小权限、轮换日期记录；不可把值复制入证据。
4. 断网/超时/Apple API 不可用/模型 5xx/账本不可用/数据删除失败：均验证本地功能不断、托管 fail closed、输入保留、无额外扣额。
5. iPhone 与 iPad，A4/Letter、长文本、中英、动态字体下生成 PDF；在 Files/分享目标和系统打印中比对同一输出；由人工确认未截断/重叠、页数、排序和项目数。
6. 公开隐私 URL、App Store Connect 隐私问卷、应用内入口及中英仓库文档逐项比对；删除请求和可选统计删除在 Production 演练完成。
7. 漏斗事件在 Production 测试 cohort 中按定义去重、无敏感内容；可从原始事件复算三个 Beta 决策门槛与 30 天成本率。

发布只有在上述自动化全绿、七类人工/E2E 全部通过、已确认的数据保留与删除要求已实现并演练、以及未发现把 Sandbox/原型当 Production 的文案后才可进行。任何一项失败均阻止 Beta 发布，不以“功能可演示”豁免。
